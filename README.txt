دعوة ذكرى مصطفى رشيد علي
الملفات داخل ZIP بدون مجلدات:
- index.html: صفحة الدعوة
- mustafa-portrait.jpg: صورة المرحوم
- design-preview.png: معاينة التصميم
- README.txt: تعليمات النشر

الأزرار تفاعلية:
1) ختمة القرآن: تفتح khatma.eu (إنشاء الختمة يتم من المنصة).
2) الدعاء والكلمة الطيبة: كتابة نص ونسخه أو إرساله عبر واتساب.
3) الصور والذكريات: عرض الصورة ومعاينة التصميم.
4) مشاركة الدعوة: مشاركة رابط الصفحة أو نسخه.
5) معلومات العزاء: تفاصيل التاريخ وتنزيل ملف تقويم.
6) نسخ دعاء له: نسخ الدعاء أو إرساله عبر واتساب.

توجد أشعة ضوء ولمعات وتوهج متحرك، مع احترام إعداد تقليل الحركة بالجهاز.

رفع GitHub Pages:
- فك ضغط ZIP.
- ارفع الملفات الأربعة مباشرة إلى جذر المستودع، بدون فولدر.
- Settings > Pages > Deploy from a branch > main > /(root) > Save.
- بعد النشر استخدم رابط GitHub Pages لمشاركة الدعوة.


الصوت:
- الملف tilawat-al-mulk.mp3 هو التلاوة المضافة.
- الصفحة تحاول تشغيله تلقائيًا عند الفتح.
- بعض متصفحات الموبايل تمنع التشغيل التلقائي للصوت؛ في هذه الحالة اضغط زر «تشغيل التلاوة» أو المس الصفحة مرة واحدة.
- ارفع ملف الصوت بجانب index.html في جذر المستودع.
